# Bank Soal Cipher Wars

Materi: **Fungsi** — Fungsi Linear (A), Komposisi Fungsi (B), Fungsi Invers (C), dan Enkripsi (finisher boss).

Format: pilihan ganda A–D, satu jawaban benar. Setiap soal diberi kode `S<sektor>-<nomor>` dan label materi.

## Peta Kesulitan per Sektor

| Sektor | Musuh | Materi | Fokus |
|---|---|---|---|
| 1 | Sentinel | A | Menghitung nilai fungsi, mencari x |
| 2 | Hyena | A | Gradien, rumus dari dua titik, soal cerita |
| 3 | Aegis | A + B | Linear lanjut, nilai komposisi |
| 4 | Null Snake | B | Rumus komposisi f∘g, g∘f, f∘f |
| 5 | **REX (Boss)** | A + B | Komposisi kuadrat, tiga fungsi, parameter |
| 6 | Virus | C | Invers fungsi linear dasar |
| 7 | Mirror | C | Invers pecahan, invers non-linear, soal cerita |
| 8 | Fox | B | Mencari f atau g, syarat f∘g = g∘f |
| 9 | Omega | C (+B) | Invers fungsi rasional, invers komposisi |
| 10 | **NEXUS (Boss Akhir)** | A + B + C | Campuran tersulit |

**Aturan finisher enkripsi:** soal enkripsi hanya muncul di sektor 5 dan 10, **satu kali** per pertarungan, sebagai serangan penutup saat HP boss sudah rendah. Game mengambil satu soal secara acak dari pool finisher sektor itu.

## Sektor 1 — Fungsi Linear Dasar

**S1-1 [A].** `f(x) = 2x + 5`. Nilai `f(3)` = ...
A. 11  B. 10  C. 16  D. 8
> **Kunci: A.** 2·3 + 5 = 11.

**S1-2 [A].** `f(x) = 4x − 1`. Nilai `f(−2)` = ...
A. −7  B. −9  C. 9  D. 7
> **Kunci: B.** 4·(−2) − 1 = −9.

**S1-3 [A].** `f(x) = x/2 + 3`. Nilai `f(8)` = ...
A. 4  B. 11  C. 7  D. 19
> **Kunci: C.** 8/2 + 3 = 7.

**S1-4 [A].** `f(x) = 3x + 2`. Jika `f(a) = 14`, maka `a` = ...
A. 4  B. 5  C. 44  D. 16/3
> **Kunci: A.** 3a = 12 → a = 4.

**S1-5 [A].** `f(x) = 5 − 2x`. Jika `f(x) = −3`, maka `x` = ...
A. −4  B. 1  C. 11  D. 4
> **Kunci: D.** −2x = −8 → x = 4.

**S1-6 [A].** `f(x) = 6x − 4`. Nilai `f(0) + f(1)` = ...
A. 2  B. −2  C. −6  D. 6
> **Kunci: B.** (−4) + 2 = −2.

## Sektor 2 — Gradien, Rumus, dan Soal Cerita

**S2-1 [A].** Gradien garis melalui (2, 1) dan (5, 10) adalah ...
A. 3  B. 1/3  C. 9  D. 4
> **Kunci: A.** (10 − 1)/(5 − 2) = 3.

**S2-2 [A].** Grafik `f(x) = −3x + 7` memotong sumbu-y di titik ...
A. (7, 0)  B. (0, −3)  C. (0, 7)  D. (7/3, 0)
> **Kunci: C.** x = 0 → f(0) = 7.

**S2-3 [A].** Fungsi linear dengan `f(0) = −2` dan `f(3) = 10` adalah ...
A. 3x − 2  B. 4x − 2  C. 4x + 2  D. −2x + 4
> **Kunci: B.** b = −2; a = 12/3 = 4.

**S2-4 [A].** `f(x) = ax + b`, `f(1) = 7`, `f(4) = 16`. Nilai `f(10)` = ...
A. 37  B. 30  C. 34  D. 40
> **Kunci: C.** 3a = 9 → a = 3, b = 4 → f(10) = 34.

**S2-5 [A].** Tarif ojek online: Rp8.000 + Rp2.500 per km. Tarif untuk 6 km adalah ...
A. Rp23.000  B. Rp15.000  C. Rp20.500  D. Rp25.500
> **Kunci: A.** f(x) = 2500x + 8000 → f(6) = 23.000.

**S2-6 [A].** Kuota internet 30 GB berkurang 1,5 GB per hari. Kuota habis setelah ... hari.
A. 15  B. 20  C. 30  D. 45
> **Kunci: B.** 30 − 1,5x = 0 → x = 20.

## Sektor 3 — Linear Lanjut dan Nilai Komposisi

**S3-1 [A].** `f(x) = 2x − 7` dan `g(x) = −x + 5` bernilai sama saat `x` = ...
A. −4  B. 2  C. 4  D. 12
> **Kunci: C.** 3x = 12 → x = 4.

**S3-2 [A].** Fungsi linear dengan `f(2) = 5` dan `f(−1) = −4`. Nilai `f(5)` = ...
A. 14  B. 15  C. 11  D. 16
> **Kunci: A.** a = 9/3 = 3, b = −1 → f(5) = 14.

**S3-3 [B].** `f(x) = 3x + 1`, `g(x) = x + 4`. Nilai `(f∘g)(2)` = ...
A. 11  B. 19  C. 10  D. 21
> **Kunci: B.** g(2) = 6 → f(6) = 19.

**S3-4 [B].** `f(x) = x − 5`, `g(x) = 2x`. Nilai `(g∘f)(7)` = ...
A. 9  B. −3  C. 4  D. 14
> **Kunci: C.** f(7) = 2 → g(2) = 4.

**S3-5 [B].** `f(x) = x²`, `g(x) = x − 3`. Nilai `(g∘f)(5)` = ...
A. 4  B. 22  C. 16  D. 28
> **Kunci: B.** f(5) = 25 → g(25) = 22.

**S3-6 [B].** `f(x) = 2x + 1`. Nilai `(f∘f)(3)` = ...
A. 14  B. 13  C. 49  D. 15
> **Kunci: D.** f(3) = 7 → f(7) = 15.

## Sektor 4 — Rumus Komposisi

**S4-1 [B].** `f(x) = x + 4`, `g(x) = 3x`. Maka `(f∘g)(x)` = ...
A. 3x + 4  B. 3x + 12  C. 3x + 7  D. x + 12
> **Kunci: A.** f(3x) = 3x + 4.

**S4-2 [B].** `f(x) = x + 4`, `g(x) = 3x`. Maka `(g∘f)(x)` = ...
A. 3x + 4  B. 3x + 7  C. 3x + 12  D. 4x + 3
> **Kunci: C.** g(x + 4) = 3x + 12.

**S4-3 [B].** `f(x) = 2x − 3`, `g(x) = 4x + 1`. Maka `(f∘g)(x)` = ...
A. 8x − 11  B. 8x − 1  C. 8x + 1  D. 6x − 2
> **Kunci: B.** 2(4x + 1) − 3 = 8x − 1.

**S4-4 [B].** `f(x) = 5x`, `g(x) = x − 2`. Maka `(g∘f)(x)` = ...
A. 5x − 10  B. x + 3  C. 5x − 2  D. 5x + 2
> **Kunci: C.** g(5x) = 5x − 2.

**S4-5 [B].** `f(x) = 3x − 2`. Maka `(f∘f)(x)` = ...
A. 9x − 6  B. 9x − 8  C. 9x − 4  D. 6x − 4
> **Kunci: B.** 3(3x − 2) − 2 = 9x − 8.

**S4-6 [B].** `f(x) = x + 1`, `g(x) = x²`. Maka `(g∘f)(x)` = ...
A. x² + 1  B. x² + x + 1  C. 2x + 1  D. x² + 2x + 1
> **Kunci: D.** (x + 1)² = x² + 2x + 1.

## Sektor 5 — BOSS REX (Linear + Komposisi)

**S5-1 [B].** `f(x) = 2x + 3`, `g(x) = x² − 1`. Maka `(f∘g)(x)` = ...
A. 2x² + 1  B. 4x² + 12x + 8  C. 2x² + 2  D. 2x² − 1
> **Kunci: A.** 2(x² − 1) + 3 = 2x² + 1.

**S5-2 [B].** `f(x) = 2x + 3`, `g(x) = x² − 1`. Maka `(g∘f)(x)` = ...
A. 2x² + 1  B. 4x² + 9  C. 4x² + 12x + 8  D. 4x² + 6x + 8
> **Kunci: C.** (2x + 3)² − 1 = 4x² + 12x + 8.

**S5-3 [B].** `f(x) = x − 1`, `g(x) = 3x`, `h(x) = x + 2`. Nilai `(f∘g∘h)(1)` = ...
A. 5  B. 8  C. 6  D. 9
> **Kunci: B.** h(1) = 3 → g(3) = 9 → f(9) = 8.

**S5-4 [B].** `f(x) = 4x + k`, `g(x) = x + 1`, dan `(f∘g)(2) = 17`. Nilai `k` = ...
A. 5  B. 9  C. 3  D. 1
> **Kunci: A.** g(2) = 3 → 12 + k = 17 → k = 5.

**S5-5 [B].** `f(x) = x + 3` dan `(f∘g)(x) = 2x + 7`. Maka `g(x)` = ...
A. 2x + 10  B. 2x + 7  C. 2x + 4  D. x + 4
> **Kunci: C.** g(x) + 3 = 2x + 7 → g(x) = 2x + 4.

**S5-6 [A+B].** `f` linear dengan `f(1) = 4` dan `(f∘f)(1) = 10`. Maka `f(x)` = ...
A. 3x + 1  B. 2x + 2  C. x + 3  D. 6x − 2
> **Kunci: B.** a + b = 4 dan f(4) = 4a + b = 10 → a = 2, b = 2.

### Finisher Enkripsi Sektor 5 (pilih satu secara acak)

Konversi huruf: `A=0, B=1, ..., Z=25`, operasi `mod 26`.

**F5-a.** Caesar `E(x) = (x + 3) mod 26`. Enkripsi `KODE` = ...
A. NRGH  B. LPEF  C. HLAB  D. NRHG
> **Kunci: A.** K→N, O→R, D→G, E→H.

**F5-b.** Pesan `VLVWHP` dienkripsi Caesar geser 3. Pesan aslinya = ...
A. SKSTEM  B. SYSTEM  C. SISTEM  D. YOYZKS
> **Kunci: C.** Dekripsi D(y) = (y − 3) mod 26 (invers dari E).

**F5-c.** `E(x) = (x + 5) mod 26`. Enkripsi `BUG` = ...
A. GZL  B. GYL  C. FZL  D. GZK
> **Kunci: A.** B(1)→6=G, U(20)→25=Z, G(6)→11=L.

## Sektor 7 — Invers Lanjut dan Soal Cerita

**S7-1 [C].** Invers `f(x) = (3x − 2)/4` adalah ...
A. (4x + 2)/3  B. (4x − 2)/3  C. (3x + 2)/4  D. 4/(3x − 2)
> **Kunci: A.** 4y = 3x − 2 → x = (4y + 2)/3.

**S7-2 [C].** Invers `f(x) = −2x + 6` adalah ...
A. (x − 6)/2  B. (x + 6)/2  C. (6 − x)/2  D. −2x − 6
> **Kunci: C.** 2x = 6 − y → x = (6 − y)/2.

**S7-3 [C].** Invers `f(x) = x/3 + 2` adalah ...
A. 3x − 2  B. 3x − 6  C. 3(x + 2)  D. (x − 2)/3
> **Kunci: B.** x = 3(y − 2) = 3y − 6.

**S7-4 [C].** `f(x) = 5x + 1`. Nilai `f⁻¹(−9)` = ...
A. −44  B. −8/5  C. 2  D. −2
> **Kunci: D.** 5x + 1 = −9 → x = −2.

**S7-5 [C].** `f(x) = x³ + 1`. Nilai `f⁻¹(9)` = ...
A. 2  B. 730  C. ∛10  D. 3
> **Kunci: A.** f⁻¹(x) = ∛(x − 1) → ∛8 = 2.

**S7-6 [C].** Konversi suhu `F = (9/5)C + 32`. Dengan fungsi inversnya, 77°F sama dengan ...
A. 45°C  B. 25°C  C. 13°C  D. 60°C
> **Kunci: B.** C = (5/9)(F − 32) = (5/9)·45 = 25.

## Sektor 8 — Komposisi Lanjut

**S8-1 [B].** `f(x) = 2x + 3` dan `(f∘g)(x) = 6x − 1`. Maka `g(x)` = ...
A. 3x − 4  B. 3x − 2  C. 3x + 1  D. 6x − 4
> **Kunci: B.** 2g(x) + 3 = 6x − 1 → g(x) = 3x − 2.

**S8-2 [B].** `g(x) = 2x + 1` dan `(f∘g)(x) = 10x + 3`. Maka `f(x)` = ...
A. 5x + 3  B. 10x − 2  C. 5x − 2  D. 5x + 2
> **Kunci: C.** 10x + 3 = 5(2x + 1) − 2 → f(x) = 5x − 2.

**S8-3 [B].** `f(x) = x + 2`. Maka `(f∘f∘f)(x)` = ...
A. x + 6  B. 3x + 2  C. x + 8  D. 3x + 6
> **Kunci: A.** Setiap f menambah 2.

**S8-4 [B].** `g(x) = x + 3` dan `(f∘g)(x) = x² + 6x + 10`. Maka `f(x)` = ...
A. x² + 3  B. x² + 1  C. x² + 6x + 1  D. x + 1
> **Kunci: B.** x² + 6x + 10 = (x + 3)² + 1 → f(x) = x² + 1.

**S8-5 [B].** `f(x) = 3x + b`, `g(x) = 2x + 1`. Agar `f∘g = g∘f`, nilai `b` = ...
A. 1  B. 3  C. 2  D. −2
> **Kunci: C.** 6x + 3 + b = 6x + 2b + 1 → b = 2.

**S8-6 [B].** `f(x) = 2x − 1`, `g(x) = x²`. Jika `(g∘f)(x) = 9`, nilai `x` yang memenuhi ...
A. 2 atau 1  B. 2 atau −1  C. −2 atau 1  D. 5 atau −4
> **Kunci: B.** (2x − 1)² = 9 → 2x − 1 = ±3 → x = 2 atau x = −1.

## Sektor 9 — Invers Rasional dan Invers Komposisi

**S9-1 [C].** Invers `f(x) = (x + 3)/(x − 2)`, `x ≠ 2`, adalah ...
A. (2x + 3)/(x − 1), x ≠ 1  B. (x − 2)/(x + 3)  C. (2x − 3)/(x + 1)  D. (x + 3)/(x − 2)
> **Kunci: A.** y(x − 2) = x + 3 → x(y − 1) = 2y + 3.

**S9-2 [C].** Invers `f(x) = (2x − 3)/(x + 4)`, `x ≠ −4`, adalah ...
A. (4x − 3)/(x − 2)  B. (4x + 3)/(2 − x), x ≠ 2  C. (x + 4)/(2x − 3)  D. (3 − 4x)/(x + 2)
> **Kunci: B.** x(y − 2) = −4y − 3 → x = (4y + 3)/(2 − y).

**S9-3 [C].** Invers `f(x) = 3/(x − 1)`, `x ≠ 1`, adalah ...
A. 3/(x + 1)  B. x/(x + 3)  C. (x + 3)/x, x ≠ 0  D. (3 + x)/(x − 1)
> **Kunci: C.** x − 1 = 3/y → x = (y + 3)/y.

**S9-4 [B+C].** `f(x) = 2x + 1`, `g(x) = x − 3`. Maka `(f∘g)⁻¹(x)` = ...
A. (x − 5)/2  B. 2x + 5  C. (x + 1)/2 − 3  D. (x + 5)/2
> **Kunci: D.** f∘g = 2x − 5 → invers (x + 5)/2. Cek: g⁻¹∘f⁻¹ = (x − 1)/2 + 3.

**S9-5 [B+C].** `f(x) = 3x`, `g(x) = x + 4`. Nilai `(g∘f)⁻¹(19)` = ...
A. 61  B. 5  C. 23/3  D. 7
> **Kunci: B.** g∘f = 3x + 4 → (19 − 4)/3 = 5.

**S9-6 [C].** Invers `f(x) = (x + 2)/(x − 1)`, `x ≠ 1`, adalah ...
A. (x − 1)/(x + 2)  B. (x − 2)/(x + 1)  C. (x + 2)/(x − 1)  D. (2 − x)/(x + 1)
> **Kunci: C.** x(y − 1) = y + 2 → fungsi ini invers dirinya sendiri.

## Sektor 10 — BOSS NEXUS (Campuran Tersulit)

**S10-1 [B+C].** `f⁻¹(x) = (x − 1)/2` dan `g(x) = x + 5`. Maka `(f∘g)(x)` = ...
A. 2x + 6  B. (x + 4)/2  C. 2x + 11  D. 2x + 5
> **Kunci: C.** f(x) = 2x + 1 → f(x + 5) = 2x + 11.

**S10-2 [B+C].** `f(x) = 2x − 3` dan `(f∘g)(x) = 4x + 1`. Maka `g⁻¹(x)` = ...
A. (x − 2)/2  B. 2x + 2  C. (x + 2)/2  D. (x − 1)/4
> **Kunci: A.** 2g − 3 = 4x + 1 → g(x) = 2x + 2 → g⁻¹(x) = (x − 2)/2.

**S10-3 [C].** `f(x) = (x + 1)/(x − 3)`, `x ≠ 3`. Nilai `f⁻¹(2)` = ...
A. 3  B. −7  C. 7  D. 5
> **Kunci: C.** (x + 1)/(x − 3) = 2 → x + 1 = 2x − 6 → x = 7.

**S10-4 [C].** `f(x) = x² + 2x` untuk `x ≥ −1`. Maka `f⁻¹(x)` = ...
A. √x − 1  B. √(x + 1) − 1  C. √(x − 1) + 1  D. √(x + 2)
> **Kunci: B.** x² + 2x = (x + 1)² − 1 → y + 1 = (x + 1)² → x = √(y + 1) − 1.

**S10-5 [B+C].** `f(x) = 2x + 3`. Nilai `(f∘f⁻¹∘f)(4)` = ...
A. 4  B. 11  C. 19  D. 8
> **Kunci: B.** f∘f⁻¹ adalah fungsi identitas → hasilnya f(4) = 11.

**S10-6 [A+B].** `f(x) = ax + b` dengan `a > 0` dan `(f∘f)(x) = 9x + 8`. Maka `f(x)` = ...
A. 3x + 4  B. 9x + 2  C. 3x + 2  D. 3x + 8
> **Kunci: C.** a² = 9 → a = 3; ab + b = 4b = 8 → b = 2.

### Finisher Enkripsi Sektor 10 (pilih satu secara acak)

**F10-a.** Affine cipher `E(x) = (5x + 8) mod 26`. Enkripsi `RPL` = ...
A. PLF  B. PFL  C. RPL  D. FPL
> **Kunci: B.** R(17): 93 mod 26 = 15 = P; P(15): 83 mod 26 = 5 = F; L(11): 63 mod 26 = 11 = L.

**F10-b.** Fungsi dekripsi (invers) dari `E(x) = (5x + 8) mod 26` adalah ...
A. 5(y − 8) mod 26  B. (y − 8)/5  C. 21(y − 8) mod 26  D. (21y − 8) mod 26
> **Kunci: C.** Invers 5 modulo 26 adalah 21 karena 5·21 = 105 = 4·26 + 1.

**F10-c.** Affine cipher `E(x) = (3x + 1) mod 26`. Enkripsi `MAT` = ...
A. LBG  B. MBT  C. KBG  D. LAG
> **Kunci: A.** M(12): 37 mod 26 = 11 = L; A(0): 1 = B; T(19): 58 mod 26 = 6 = G.
