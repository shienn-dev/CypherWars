MATERI: KOMPOSISI FUNGSI

(f ∘ g)(x) = f(g(x)) — artinya: hitung dulu g(x), lalu masukkan hasilnya ke f. Urutan dibaca dari dalam ke luar.

Contoh

f(x) = 2x + 1, g(x) = x². Maka (f ∘ g)(3):

(1) g(3) = 3² = 9  →  (2) f(9) = 2·9 + 1 = 19.

Jadi (f ∘ g)(3) = 19.

Kesalahan umum:

  • Membalik urutan: (f ∘ g)(x) bukan g(f(x)).
  • Mengalikan fungsi: (f ∘ g)(x) bukan f(x) · g(x).
  • Lupa substitusi: semua x pada f harus diganti seluruh g(x).
